## Results to discuss

- GLYX exact-repeat control: the same 584 files, representing 1.958 GB, added again for 919,848 additional archive/recovery-record bytes. 99.953% incremental byte avoidance; all 584 restored exactly. The existing archive and required restoration dependencies remain needed.
- TokenHoloFold supported-task study: 300/300 exact results and zero model-provider calls. On 237 mutually correct paired cases, the ratio of median complete times was 10.61× against the measured API route. A strong conventional local route also used no provider calls and was faster.
- Seed State CPU validation repeat: 2,667.644× lower mean process CPU time on compatible deterministic fixtures, with retained atlas/receipts already available; their construction was outside the validation timer.
- Seed State GPU retained-tile study: 4,096× less dispatched logical GPU work for one changed tile of 4,096. The repeat full-output operational update mean paired ratio was 20.919×. Initial state creation and independent full-output evaluation are separate costs.

These examples identify promising evaluation workloads. Each has its own baseline, platform and cost boundary; customers should compare the complete workflow they will run.
